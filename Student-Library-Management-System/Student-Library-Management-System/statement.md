# Project Statement

## Project Title
Student Library Management System

## Problem Statement
Keeping track of books manually can become confusing when some books are available and others have been borrowed. This project provides a simple terminal-based Python program for keeping these records in one place.

## Project Scope
The project covers adding, viewing, searching, borrowing, returning, and removing books. It also keeps a small library status summary and saves records in a JSON file.

The project does not cover user accounts, online access, payment or fine systems, GUI development, or a database server.

## Target Users
Students or anyone managing a small personal or academic collection of books.

## High-Level Features
1. Book management
2. Book search
3. Borrow and return tracking
4. Library status summary
5. JSON-based storage
6. Basic input validation and error handling
