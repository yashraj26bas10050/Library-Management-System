# Manual Test Guide

Run:

```bash
python main.py
```

Then:

1. View the existing books.
2. Add a new book.
3. Search for it.
4. Borrow it.
5. View the list and confirm it says `Borrowed`.
6. Return it.
7. Remove it.
8. Try an invalid menu number.
9. Restart the program and confirm the saved data is still present.
